### About the Project

Yassine created **tinny-backend** to deliver an unbloated, high-velocity backend routing solution for Node.js and Bun with native WebSockets, recursive static file serving, and cookie handling—without pulling in dozens of heavy external dependencies.

Contributions, feedback, and questions are always welcome. Connect on GitHub or LinkedIn!
